# Silent KillAura для visualmod (Minecraft 1.21.11, Mojang-маппинги)

Исходники твоего мода в репозитории не лежат, поэтому это **накладка**: 3 файла + правка списка миксинов.
Пути в `visualmod-patch/src/...` совпадают с путями в проекте мода.

| Файл | Что делать |
|---|---|
| `com/visualmod/module/KillAura.java` | **заменить** старый |
| `com/visualmod/mixin/LocalPlayerSilentMixin.java` | **добавить** |
| `com/visualmod/mixin/KeyboardInputSilentMixin.java` | **добавить** |
| `resources/visualmod.mixins.json` | **заменить** (или просто дописать в `"client"` две строки: `KeyboardInputSilentMixin`, `LocalPlayerSilentMixin`) |

Больше ничего не менять: `ModuleManager.KILL_AURA`, `sprintReset`, `onRenderFrame`, `onHandleKeybinds`, `onTick`
и все id настроек остались прежними, твои сохранённые настройки подхватятся.

## Как это работает
За тик игрока:
1. **Начало `LocalPlayer.tick`**: выбирается цель, считается silent-поворот, на время тика игроку подставляется он.
   Физика и пакет движения идут с этим поворотом, поэтому поворот, ввод и движение для сервера/Grim согласованы.
2. **Конец `LocalPlayer.tick`**: камера возвращается. У тебя на экране ничего не дёргается.
3. **Следующий тик, до пакетов движения**: бьём. Это ванильный порядок (удар раньше пакета движения),
   сервер уже знает поворот с прошлого тика, поэтому удар не «мажет по старому повороту».

## Что сделано под Grim (movement / aim / inventory включены)
- **Сетка чувствительности (GCD)**: повороты кратны шагу мыши (`f³·8·0.15`, `f = sens·0.6+0.2`), иначе aim-проверки видят «нечеловеческие» повороты.
- **Коррекция движения**: W/A/S/D пересчитываются в ближайшую из 8 комбинаций, чтобы ты шёл туда, куда смотрит камера.
  Меняются и `keyPresses` (их видит сервер), и `moveVector`, так что предсказание движения совпадает.
- **Дальность до ближайшей точки хитбокса**, как на сервере. Удар только если поворот прошлого тика реально попадает лучом в хитбокс.
- Дальность по умолчанию 3.0, один удар за раз, без мульти-ауры, удар только при полном кулдауне.
- Inventory-проверки KillAura не трогает.

## Настройки
Дальность, зона захвата, плавность, макс. скорость, **упреждение**, по вертикали, **сетка чувствительности**,
**коррекция движения**, **тайминг крита**, только с оружием, не бить союзников, сброс спринта.
Если на HvH-сервере Grim ослаблен (reach и т.п.), дальность можно поднять.
