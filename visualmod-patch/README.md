# KillAura v2 для visualmod

Замена файла `com/visualmod/module/KillAura.java` в исходниках мода (публичный интерфейс не менялся:
`ModuleManager.KILL_AURA`, `sprintReset`, `onRenderFrame`, `onHandleKeybinds`, `onTick`, `setEnabled`,
все id настроек сохранены — старые сохранённые настройки подхватятся).

Исходники в репозитории **не лежат**: `visualmod-1.0.0.jar` декомпилирован только для чтения.
Класс написан на Mojang-названиях (как у твоих миксинов: `LocalPlayer`, `MultiPlayerGameMode` и т.д.)
под Minecraft 1.21.11. Собрать и проверить его я здесь не мог.

## Почему старая килка мазала
1. Нужен был `client.hitResult` ровно на цели. У него дальность 3.0 и он теряется об стену/другого моба.
2. Две «стабильных» тика перед каждым ударом.
3. Прицел в центр хитбокса с отставанием (медленный поворот, нет упреждения) — бегущий игрок убегал из луча.
4. Пакет атаки уходит **раньше** пакета с новым поворотом, сервер бил по повороту прошлого тика.

## Новые настройки
- **Упреждение** (`predict`, 1.5 тика), **Тайминг крита** (`crits`).
- Дальность по умолчанию 3.0 (подними до 3.2–3.5, если у вас на HvH ослаблен reach).
- Зона захвата 120°, плавность 2, макс. скорость 540°/с.
