# Бот «Интересное из моих каналов»

Telegram-бот, который читает ваши каналы и по нажатию кнопки присылает
короткую подборку самого интересного: заголовок, пересказ в 1–3 предложения,
почему это стоит внимания, и ссылки на оригинальные посты. Одинаковые новости
из разных каналов склеиваются в один пункт. Отбор делает **бесплатная**
языковая модель по вашему описанию интересов.

```
🔥 Интересное с прошлого раза (за 9 ч)
Просмотрено 214 постов из 23 каналов

1. Заголовок новости
Пересказ в 1–3 предложениях: кто, что произошло, цифры.
→ Чем это интересно именно вам
🔗 Канал А · Канал Б

Модель: …
```

## Кнопки

| Кнопка | Что делает |
|---|---|
| 🔥 **Найти интересное** | посты, вышедшие после прошлого нажатия (в первый раз — за сутки) |
| 🕐 **За 24 ч** | всё за последние сутки, независимо от прошлых нажатий |
| 📋 **Каналы** | список каналов; удалить канал — кнопкой ❌ |
| ⚙️ **Интересы** | своими словами описать, что вам интересно, а что нет |

**Добавить канал:** перешлите боту любой пост из канала или отправьте
`@канал` или ссылку `t.me/канал`. Можно несколько сразу.
**Пока список пуст, бот читает все каналы, на которые вы подписаны.**

## Как это устроено

Обычный бот в Telegram не может читать чужие каналы, поэтому у программы
три части:

1. **Ваш аккаунт** (библиотека Telethon) читает каналы: и подписки, включая
   приватные, и любые публичные каналы.
2. **Бесплатная языковая модель** отбирает и пересказывает новости.
3. **Бот** (aiogram) показывает кнопки и присылает подборку. Отвечает только
   вам (`OWNER_ID`), всем остальным пишет «Это личный бот».

## Бесплатная модель: что выбрать

Бот работает с любым сервисом, у которого OpenAI-совместимый API. Сервис
меняется тремя строками в `.env`, код трогать не нужно.

| Вариант | Плюсы | Минусы |
|---|---|---|
| **OpenRouter** (по умолчанию) | ключ без карты, ничего не нужно устанавливать | 50 запросов в день; модель каждый раз случайная, качество скачет |
| **Google Gemini** | хорошее качество, читает много постов за раз | в России официально не работает |
| **Ollama** (модель на вашем компьютере) | без лимитов, данные никуда не уходят | нужен мощный компьютер (от 16 ГБ памяти), медленнее, качество ниже |

Одно нажатие кнопки обычно расходует 1 запрос (максимум 2, если модель
ответила не по формату). 50 бесплатных запросов в день у OpenRouter с запасом
хватает на ручные нажатия.

### OpenRouter (по умолчанию)

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai) и создайте
   ключ на странице [Keys](https://openrouter.ai/keys). Карта не нужна.
2. Впишите его в `.env`: `LLM_API_KEY=sk-or-v1-…`. Остальное уже настроено:
   `LLM_MODEL=openrouter/free` сам выбирает свободную бесплатную модель
   (какая ответила, бот пишет внизу подборки).
3. Если бот пишет про «настройки приватности», откройте
   [Settings → Privacy](https://openrouter.ai/settings/privacy) и разрешите
   бесплатные модели. Бесплатные провайдеры могут сохранять запросы.

Чтобы качество было стабильнее, укажите одну конкретную бесплатную модель
вместо случайной: выберите её в [списке моделей](https://openrouter.ai/models?max_price=0)
и впишите её id с окончанием `:free` в `LLM_MODEL`.

### Google Gemini

Ключ — в [Google AI Studio](https://aistudio.google.com/apikey). В `.env`:

```env
LLM_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
LLM_API_KEY=AIza...
LLM_MODEL=<название бесплатной flash-модели из AI Studio>
MAX_INPUT_CHARS=300000
```

На бесплатном тарифе Google может использовать запросы для улучшения своих продуктов.

### Ollama (на своём компьютере)

1. Установите [Ollama](https://ollama.com) и скачайте модель: `ollama pull qwen3:8b`.
2. Запускайте Ollama с увеличенным контекстом, иначе она молча обрежет посты:
   `OLLAMA_CONTEXT_LENGTH=32768 ollama serve`.
3. В `.env`:

```env
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=
LLM_MODEL=qwen3:8b
MAX_INPUT_CHARS=30000
```

## Установка

Нужен Python 3.10 или новее и компьютер или сервер, где бот будет работать.

### 1. Получите ключи

| Что | Где взять |
|---|---|
| `BOT_TOKEN` | напишите [@BotFather](https://t.me/BotFather) → `/newbot` |
| `OWNER_ID` | ваш числовой id: напишите [@userinfobot](https://t.me/userinfobot) |
| `TG_API_ID`, `TG_API_HASH` | [my.telegram.org](https://my.telegram.org) → API development tools → создайте приложение (название любое) |
| `LLM_API_KEY` | бесплатный ключ OpenRouter, см. выше |

### 2. Установите и настройте

```bash
cd news-bot
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # затем впишите ключи в .env
```

### 3. Один раз войдите в аккаунт Telegram

```bash
python login.py
```

Программа спросит номер телефона, код из Telegram и пароль двухэтапной
проверки, если он включён. Сессия сохранится в `data/user.session`.

### 4. Запустите бота

```bash
python -m news_bot
```

Откройте своего бота в Telegram, нажмите **Start**, затем **🔥 Найти интересное**.

## Настройки (`.env`)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `LLM_BASE_URL` | OpenRouter | адрес сервиса модели |
| `LLM_MODEL` | `openrouter/free` | модель |
| `TOP_N` | 7 | сколько новостей в подборке, максимум |
| `DEFAULT_HOURS` | 24 | период для кнопки «За 24 ч» и первого запуска |
| `MAX_LOOKBACK_HOURS` | 72 | «с прошлого раза», но не дальше стольких часов |
| `MAX_POSTS_PER_CHANNEL` | 40 | не больше стольких свежих постов с канала |
| `MAX_CHANNELS` | 60 | лимит каналов, если читаются все подписки |
| `MAX_INPUT_CHARS` | 60000 | сколько текста отправлять модели за раз |
| `MAX_POST_CHARS` | 1000 | длинные посты обрезаются до этой длины |

Бесплатные модели не принимают слишком длинный текст. Если постов больше,
чем влезает в `MAX_INPUT_CHARS`, бот берёт самые популярные посты каждого
канала по просмотрам и пишет в подборке, сколько постов пропустил. Если
пропускает много, сузьте список каналов, нажимайте кнопку чаще или
переходите на Gemini.

## Безопасность

- **`data/user.session` — это полный доступ к вашему аккаунту Telegram.**
  Никому его не передавайте и не коммитьте; `.gitignore` уже исключает его
  вместе с `.env`. Отозвать доступ можно в Telegram: Настройки → Устройства.
- Бот только читает каналы: ничего не пишет и не подписывается от вашего имени.
- Тексты постов отправляются в выбранный сервис модели. Бесплатные сервисы
  могут сохранять их и учиться на них; если это важно, используйте Ollama.

## Работа 24/7

Бот работает, пока запущена программа. Чтобы он не выключался, запустите его
на сервере, например через systemd:

```ini
# /etc/systemd/system/news-bot.service
[Unit]
Description=News digest bot
After=network-online.target

[Service]
WorkingDirectory=/home/USER/news-bot
ExecStart=/home/USER/news-bot/.venv/bin/python -m news_bot
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now news-bot
```

Сначала выполните `python login.py` вручную на этом же сервере.
