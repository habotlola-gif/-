# Прицел-оверлей для CS2

1. Установи Python 3 (python.org), при установке отметь «Add to PATH».
2. В CS2: Настройки → Видео → режим дисплея **«Окно без рамки»** (Borderless).
3. Запусти: `python crosshair.py --color 00ff00 --dot --outline`

Клавиши: **F8** показать/скрыть, **F9** выход, **F6/F7** размер.

Параметры: `--color`, `--size`, `--gap`, `--thickness`, `--dot`, `--no-tee`, `--outline`.

⚠️ Оверлей-прицелы запрещены на FACEIT, ESEA и турнирах. VAC он не читает память игры, но используй на свой риск; на матчмейкинге Valve лучше пользуйся встроенными настройками прицела (`cl_crosshair*` в консоли).
