# LogisticaWB — зарплата водителей по данным WB Логистики

Сайт для водителей и администратора: путевые листы, отчёт с прибылью, удержания WB,
сводная ведомость. Данные берутся из WB Логистики по ключу каждого кабинета (ИП).
Нужен только Python 3.9 или новее, на Windows ничего доустанавливать не надо.

## Запуск

Windows: двойной щелчок по `start.bat`. Или в терминале:

```bash
python app.py                                  # откроется http://127.0.0.1:3000
python -m unittest discover -s tests           # тесты
```

Окно с сайтом не закрывайте, пока пользуетесь сайтом. Если порт 3000 занят, сайт сам
возьмёт следующий (3001, 3002…) и напишет адрес в окне.

Чтобы водители заходили с телефонов в той же Wi-Fi сети, запустите с `HOST=0.0.0.0`
(в cmd: `set HOST=0.0.0.0 && python app.py`) и откройте на телефоне `http://<IP компьютера>:3000`.

## Установка на сервер (VPS)

Чтобы ИП заходил на сайт сам, без вашего компьютера.

1. **Сервер.** Арендуйте VPS в России (Timeweb Cloud, Selectel, Beget, REG.RU и т. п.):
   Ubuntu 24.04 (или 22.04), 1 ядро, 1 ГБ памяти — этого достаточно. Хостинг пришлёт IP и пароль root.
2. **Загрузите архив** с компьютера (Windows — в PowerShell):
   ```
   scp logistica-wb.zip root@IP_СЕРВЕРА:
   ssh root@IP_СЕРВЕРА
   ```
3. **Установите** (на сервере):
   ```
   apt-get install -y unzip && unzip -o logistica-wb.zip && cd logistica-wb
   sudo bash deploy/install.sh
   ```
   Скрипт поставит всё нужное, включит HTTPS и автозапуск, проверит, отвечает ли WB этому
   серверу, и напечатает адрес сайта (вида `https://1-2-3-4.sslip.io`) и **код установки**.
   Со своим доменом: `sudo bash deploy/install.sh zarplata.ru` (A-запись домена — на IP сервера).
4. **Откройте адрес**, введите код установки и создайте администратора (это вы).
5. **Настройки → Кабинеты WB**: добавьте кабинет ИП — ключ (адрес с `bearer=`) и ID поставщика.
6. **Настройки → Пользователи**: добавьте ИП — роль «ИП», его кабинет, логин и пароль.
   Передайте ИП адрес сайта, логин и пароль. Больше ему ничего делать не нужно.

**Обновление:** загрузите новый архив, распакуйте поверх (`unzip -o`) и снова
`sudo bash deploy/install.sh` — данные, ключи и пароли сохранятся.

**Резервная копия:** папка `/var/lib/logistica-wb` и файл `/etc/logistica-wb.env` — только вместе:
в `.env` лежит секрет, без которого ключи WB не расшифровать.

**Ключ WB** живёт около полугода. В «Настройках» видно, сколько дней осталось; когда истечёт,
у ИП появится «Ключ устарел» — вставьте свежий адрес с `bearer=` в кабинет.

Если скрипт напишет, что WB не отвечает, или путевые не загружаются с ошибкой связи — WB блокирует
этот хостинг: попробуйте VPS у другого провайдера.

**Роли:**

| Роль | Видит | Может настраивать |
|---|---|---|
| Администратор | все кабинеты | кабинеты, ключи, пользователей, комиссию |
| ИП | только свой кабинет: отчёты по любому водителю, ведомость, путевые, удержания, остатки | только свой пароль |
| Водитель | только себя | только свой пароль |

## Первый запуск на своём компьютере

1. Сайт попросит создать администратора (ФИО, логин, пароль).
2. **Настройки → Кабинеты WB → Добавить кабинет**: название ИП и адрес страницы
   ol.wildberries.ru целиком (в нём есть `bearer=`). Так для каждого кабинета.
3. **Настройки → Сотрудники → Добавить сотрудника**: ФИО, логин, пароль. Путевые находятся
   по ID водителя WB, а если его нет — по ФИО. Если в WB ФИО записано иначе, укажите его
   в поле «ФИО в WB» (кнопка «Подтянуть ФИО из WB» покажет, как водители записаны в WB).
4. Водитель входит под своим логином и видит только свои данные.

## Разделы

| Раздел | Что показывает |
|---|---|
| Отчеты | Период (окно с календарём и быстрыми кнопками), число путевых, прибыль, текст отчёта и кнопка «Копировать отчет». Администратор выбирает сотрудника |
| Удержания WB | Две вкладки. «Удержания WB» — как страница удержаний WB: брак (с причиной), недоставленные коробки и др., путевой, водитель, сумма и штуки, итоги по типам, баланс кабинета. «Штрафы по путевым» — `fineSum` путевых со статусом |
| Остатки | Маршруты из WB (автообновление или выгрузка Excel): ШК, коробки, КГТ, парковка, норма выезда. Зелёная рамка — ШК набрали норму. Фильтр по перевозчику, поиск по маршруту и парковке |
| Путевые листы | День и кабинет → карточки путевых: номер, парковка, открыл/закрыл, ШК, коробки, суммы, штраф |
| Ведомость | Только администратору: все водители за период с удержаниями WB (колонка «Удерж. WB», галочка «Вычитать удержания WB» прямо там), прибыль, выгрузка в CSV |
| Настройки | Кабинеты и ключи, сотрудники, общий процент удержания, смена пароля |

## Как считается

1. У WB запрашивается период `from` … `to + 1 день` по каждому кабинету.
2. Удалённые путевые (`isDeleted`) отбрасываются. Путевые режутся по дате: закрытые по `closeDt`,
   незакрытые по `openDt`. Незакрытые в расчёт не входят.
3. По водителю, всё в копейках, целыми числами:
   - **Сумма всех путевых** = Σ `totalPrice` (число или `{source, parsedValue}`);
   - **Комиссия** = сумма × процент, округлённая до копейки (по умолчанию 0 % — без комиссии; задаётся в настройках);
   - **Штрафы** = Σ `fineSum` (`null` = 0);
   - **Удержания WB** = сумма удержаний WB по путевым водителя за период (можно отключить в отчёте);
   - **Прибыль** = сумма − комиссия − штрафы − удержания WB.

### Штрафы

- **Сумма** берётся из `fineSum` путевого (`null` = 0).
- **Статус** — из признаков WB: `isFineUnderConsideration` → «На рассмотрении»,
  `isApproved = true` → «Подтверждён», `isApproved = false` → «Не подтверждён»,
  иначе «Начислен». В настройках можно выбрать, вычитать ли штрафы на рассмотрении
  (по умолчанию вычитаются, в отчёте пишется «В т.ч. на рассмотрении»).
- **Вид** — если WB присылает в путевом список штрафов (поле со словом `fine`/`penalty`,
  элементы с названием и суммой) или название вида строкой (`fineTypeName` и похожие).
  Главная сумма — `fineSum`: остаток, не покрытый списком, идёт строкой «Без вида».
  В ответе по путевым, который мы знаем, видов нет, поэтому сейчас обычно будет «Без вида».

Текст отчёта повторяет приложение:

```
Зарплата партнера: Эмиров Нурали Ханахмедович
Период: 01.10.2026 - 05.10.2026
Путевых записей: 6
Сумма всех путевых: 62 011,11
Минус комиссия (20%): 12 402,22
После комиссии: 49 608,89
Штраф за брак всего 3 056,60
Штраф за опоздание или неотметка на точке маршрута всего 877,65
Сумма штрафов: 3 934,25
Минус штрафы от путевых: 3 934,25
Прибыль: 45 674,64
```

Строки с видами штрафов появляются, только когда WB присылает виды; строки о комиссии — только если она не 0.

## Проверка данных WB

В **Настройки → Кабинеты → Скачать JSON** можно сохранить ответ WB по путевым за день как есть,
чтобы проверить, какие поля в нём есть. Ключа в этом файле нет.

### Удержания WB

Берутся с drive.wb.ru тем же ключом (`client-gateway/api/v1/penalties/carrier/pretensions/page`,
по ID поставщика, постранично) и баланс (`client-gateway/api/finance/balance/v2/balances`).
В комментарии WB пишет номер путевого — по нему удержание привязывается к водителю
(путевые, которых сайт ещё не видел, ищутся в WB за месяц до периода).
Период — по дате удержания, как на странице WB. Возвращённые удержания не суммируются.

В отчёте удержания WB **вычитаются из прибыли**: в тексте появляются строки
«Удержание WB «Брак» всего …» и «Минус удержания WB: …». Галочка «Вычитать удержания WB»
прямо на странице отчёта или ведомости их отключает (выбор общий для обеих страниц и запоминается в браузере).
В ведомости водитель, у которого есть удержания, но нет закрытых путевых в периоде, тоже попадает в список.

### Остатки

Остатки подтягиваются из WB сами — тем же ключом кабинета, из отчёта
`router-bff/last-mile-report/v1/report/by-routecar` (это страница остатков на ol.wildberries.ru):

- автоматически каждые 10 минут (меняется в Настройки → «Остатки: автообновление», 0 — выключить);
- по кнопке «Обновить из WB» (не чаще раза в минуту на кабинет).

Если WB для остатков (и удержаний) требует другой ключ, а не тот, что в адресе с `bearer=`,
вставьте его в Настройки → Кабинеты → «Ключ остатков и удержаний»: на ol.wildberries.ru откройте
«Остатки», F12 → Network, запрос `by-routecar` → Request Headers → `Authorization` → Copy Value.
Ключ хранится так же зашифрованным. Если он не задан, используется основной.

Для запроса нужен **ID поставщика** кабинета — число перед названием ИП в выгрузке
(например `10105118 ИП …`). Он указывается в Настройки → Кабинеты; если поле пустое, сайт
попробует найти его в путевых листах WB. Новые данные заменяют маршруты этого перевозчика,
уехавшие маршруты пропадают.

Запасной вариант — загрузить выгрузку Excel вручную (раздел «Остатки» → «Загрузить выгрузку
Excel вручную»). Номер парковки из остатков показывается и в карточке путевого (связь по ID маршрута).

## Ключи и безопасность

- Ключи хранятся только на сервере, в `data/wb-key-*.enc`, в зашифрованном виде.
  На Windows шифрует сама система (DPAPI): расшифровать файл может только ваша учётная запись Windows.
  На других системах — AES-256-GCM, нужен пакет `cryptography` (`pip install cryptography`).
- Браузеру сервер отдаёт только срок действия ключа. В логи и код ключ не пишется.
- Пароли хранятся как PBKDF2-хеш. Сессия — cookie `HttpOnly; SameSite=Strict` на 30 дней.
  После 10 неверных паролей подряд вход с этого адреса блокируется на 10 минут.
- Если WB отвечает 401 или 403, сайт пишет «Ключ устарел, обновите» и показывает ответ WB.
- Ключ от прошлой версии (`data/wb-key.enc`) сам станет кабинетом «Кабинет 1».
- Папка `data/` в git не попадает.

## Ограничения

- API неофициальное: WB может поменять его без предупреждения.
- Один и тот же период одного кабинета запрашивается у WB не чаще раза в минуту,
  запросы к одному кабинету идут по очереди.
- WB может не пускать запросы с серверов хостинга. С домашнего компьютера работает.
