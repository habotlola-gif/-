# Зарплата водителей по данным WB Логистики

Небольшой сайт: берёт рейсы из WB Логистики за период и считает выплату каждому водителю.
Нужен только Python 3.9 или новее, на Windows ничего доустанавливать не надо.

## Запуск

Windows: двойной щелчок по `start.bat`. Или в терминале:

```bash
python app.py                                  # откроется http://127.0.0.1:3000
python -m unittest discover -s tests           # тесты
```

Окно с сайтом не закрывайте, пока пользуетесь сайтом. Если порт 3000 занят, сайт сам
возьмёт следующий (3001, 3002…) и напишет адрес в окне.

Откройте страницу, нажмите на значок ключа справа вверху и вставьте **адрес страницы
ol.wildberries.ru целиком** (в нём есть `bearer=…`). Подойдёт и сам ключ.
Сайт покажет, до какой даты ключ действует (поле `exp`, обычно около полугода).

> WB может не пускать запросы с серверов хостинга. С домашнего компьютера проверено, работает.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт |
| `HOST` | `127.0.0.1` | адрес; `0.0.0.0`, чтобы открыть сайт в локальной сети |
| `APP_PASSWORD` | — | пароль на сайт (Basic auth). Обязательно задайте, если сайт открыт в сеть |
| `WB_KEY_SECRET` | — | только не на Windows: секрет для шифрования ключа. Если не задан, создаётся `data/master.key` |
| `DATA_DIR` | `./data` | где хранить зашифрованный ключ и настройки |
| `TZ_OFFSET_HOURS` | `3` | пояс (часы от UTC), по которому считается дата у меток времени со смещением |
| `NO_BROWSER` | — | не открывать браузер при запуске |

## Как считается

1. У WB запрашивается период `from` … `to + 1 день`.
2. Удалённые рейсы (`isDeleted`) отбрасываются.
3. Рейсы режутся по дате: закрытые по `closeDt`, незакрытые по `openDt`.
   Незакрытые (`closeDt = null`) в расчёт не входят, они показаны в блоке «В пути».
4. По каждому водителю, всё в копейках, целыми числами:
   - **Сумма** = Σ `totalPrice` (число, строка или `{source, parsedValue}`);
   - **Удержание** = Сумма × процент, округлённое до копейки (по умолчанию 20 %; процент меняется на странице, кнопка ★ сохраняет его как процент по умолчанию);
   - **Штрафы** = Σ `fineSum` (`null` = 0);
   - **К выплате** = Сумма − Удержание − Штрафы.
5. Итог — сумма уже округлённых значений по водителям.

Строку водителя можно раскрыть: появятся его рейсы с маршрутом (`logRouteName`, точки с ID),
ШК, коробками, плановым пробегом и возвратами. Ведомость выгружается в CSV для Excel и печатается.

## Ключ и безопасность

- Ключ хранится только на сервере, в `data/wb-key.enc`, в зашифрованном виде.
  На Windows шифрует сама система (DPAPI): расшифровать файл может только ваша учётная запись Windows.
  На других системах — AES-256-GCM, нужен пакет `cryptography` (`pip install cryptography`),
  и лучше задать `WB_KEY_SECRET`, чтобы мастер-ключ не лежал рядом с зашифрованным файлом.
- Браузеру сервер отдаёт только срок действия, сам ключ не отдаёт. В логи и код ключ не пишется.
- Если WB отвечает 401 или 403, сайт пишет «Ключ устарел, обновите» и в скобках показывает, что именно ответил WB.
- Папка `data/` в git не попадает.

## Ограничения

- API неофициальное: WB может поменять его без предупреждения. Если формат ответа изменится,
  сайт покажет ошибку, а не посчитает неверно.
- Один и тот же период запрашивается у WB не чаще раза в минуту: ответ кешируется на 60 секунд.
  Смена процента пересчитывает ведомость без нового запроса к WB.
