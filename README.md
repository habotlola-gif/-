# Polt Client

Простой клиент-мод для Minecraft 1.21.4 (Fabric, Java 21) для своих и тестовых серверов.

## Модули
| Модуль | Клавиша по умолчанию | Описание |
|---|---|---|
| Sprint | R | авто-спринт |
| Fly | G | полёт как в креативе |
| Fullbright | B | ночное зрение |
| KillAura | K | авто-атака ближайшего игрока в радиусе 4.2 |

Клавиши меняются в настройках управления (категория «Polt Client»). Включённые модули показываются на экране.

## Сборка
```
gradle wrapper   # один раз
./gradlew build  # jar в build/libs
./gradlew runClient
```
Нужны JDK 21. Используйте только на серверах, где это разрешено.

## Добавить модуль
Создай класс в `module/impl`, унаследуй `Module`, добавь в список в `ModuleManager`, строку в `lang/en_us.json`.

## AutoSwap (сферы, талисманы)
Название конкретных предметов знать не нужно — правило ищет **ключевые слова** в имени предмета в **хотбаре**.
Правила — в `config/poltclient-swaps.json` (создаётся при первом запуске):
```json
[
  { "keywords": ["сфера", "шар"],              "key": 90 },
  { "keywords": ["талисман", "тотем", "totem"], "key": 88 }
]
```
- Бинд `Z`: в оффхенде сфера/шар — берёт **другую** сферу/шар из хотбара (A → B). В оффхенде талисман или пусто — берёт первую сферу (талик → сфера).
- Бинд `X`: то же для талисманов/тотемов.
- Предмет из оффхенда уходит на освободившийся слот хотбара, поэтому следующий бинд вернёт его обратно.
- Слова и клавиши меняются в конфиге (Z=90, X=88, C=67). Если конфиг остался от старой версии — удали его.
